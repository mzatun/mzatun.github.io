The Journey

成长历程：先用起来，再组织起来，最后一起进化

每一步都不是提前规划好的，是被真实的业务和交付问题倒逼出来的。方向始终没变：让智能体从"能答"走到"能干"，再走到"能扛"。

阶段一 · 把一个智能体用起来

五层工程范式：言 · 境 · 驭 · 环 · 图

单体功夫期——2021 提示词学术化 → 2026-08 图工程成论文，五层半年一层长出来 ｜ 方法论成文于课程教程《AI应用工程范式》（未公开）

这一时期的工作围绕单个智能体展开，后来沉淀为五层谱系——每层控制一个对象，叠加使用，不是替代关系：言·提示词工程管指令表达（知识都在模型里，问题是有没有被正确激活）；境·上下文工程管信息状态（模型不是不知道，是此刻没看到）；驭·驾驭工程管行动环境与验证（能力不只取决于模型多聪明，还取决于被放进怎样的运行环境）；环·循环工程管时间与反馈（一次做不对没关系，关键是能不能自己发现不对并收敛）；图·图工程管协作拓扑（单体的能力上限是组织问题，不是智力问题）。

言 · 提示词工程境 · 上下文工程驭 · 驾驭工程环 · 循环工程图 · 图工程
五层是叠加律：每上一层都保留前面几层的产物。但单体功夫有天花板——每个智能体仍是一座孤岛，换一个场景就要从头调教一遍，功夫不能积累。
阶段二 · 把一族智能体组织起来

新 SOA 三层：组件化 → 服务化 → 可编排化

体系工程期——解决"这么多智能体怎么不打架"

孤岛问题逼出了体系化：业务能力组件化——把每个业务场景拆成有契约（inputs / outputs / gates）的能力组件；组件能力服务化——契约写进 YAML，机器可校验，能力与实现解耦（技能挂了换技能，契约不动）；服务能力可编排化——router 负责路由、flows 负责配方，新场景只加变体参数和一条 flow，能力 ID 永不变。今天的成果落成了 6 个能力包 + 总注册表 + 机检脚本，配方跑通一次才标 verified，没跑通就诚实标 provisional。

能力包总注册表 v1.3六包格局spec = 契约router + flowsprovisional→verified 回填反孤岛条款
升级的标志：扩一个业务域，不再是从零调教，而是给现有能力加一组变体参数——功夫开始复利。
阶段三 · 向共生走

可回答 → 可执行 → 可决策

目标主线期——衡量人机关系的刻度尺

这条主线贯穿始终，也是往后的方向。可回答：问什么答什么，有出处、不编造——这是信任的地基；可执行：答完能落地，读文件、改文件、跑脚本、过机检，交付可核验的东西——这是价值的发生器；可决策：在给定约束内自己选路径、选方案，把人从判断的重复劳动里解放出来——判断权始终在人，但执行的决策正在逐步移交。今天我们正稳定站在"可执行"，向"可决策"推进。

可回答：有据可执行：落地可决策：共生

六、我 vs 我的智能体HUMAN-AI MIRROR · BOTTOM-UP

前面各节画的都是系统的技术分层（系统视角）。这一节换视角：画人与智能体的镜像对应（协作视角）。自下而上四层——具体项目 → 业务能力与赛道 → 元技能组成 → 身份画像×思维模式×行为约束。每层左列是你、右列是我。

「映射」是什么关系——三句话说清
① 不是包含，是对应。左列的每一条，都能在右列找到它的执行形态；反过来右列的每个技能，也都得服务于左列的某个真实用途。没有对应关系的技能，就是孤儿，删掉。
② 左列是因，右列是果。你先有项目、先有赛道、先有方法论，右列的契约与技能是长出来的——所以注册表里包的顺序永远跟着业务走，不反过来。
③ 映射是流动的，会长也会删。你新开一条赛道 → 右列加一条 scene 行或变体参数，能力 ID 不变（反孤岛条款）；你砍掉一条赛道 → 右列该路由清空，不要留僵尸路由假装还能用。
你平时怎么操作说给我什么（最小输入）我接手后做什么你不需要操心的
立规矩 一句原则，如"引用成果前先 ls 核实" 写进 AGENTS.md，成为我的默认行为，不用每次重复交代 不用反复提醒
提需求 给谁、解决什么、大致要什么形态 我自己查包路由、命中配方、过闸门再交付 不用指定技能名和包名
拍方向 要哪条路径、放弃哪条路径 照办，但会先告诉你代价和风险 不用考虑技术实现细节
验收 看目录实存的东西，或让我实跑机检 给可核验的证据，不给"应该没问题" 不用自己复现一遍
扩域 / 砍域 新开一条赛道，或砍掉一条 扩域只加变体参数 + 一条 flow，能力 ID 不变；砍域清空路由，不留僵尸 不用重做能力体系
一句话记住这个镜像：你负责"定什么是对的"，我负责"把它做成并证明它做成了"。
凡是需要判断的（要不要做、值不值得做、该走哪条路），留给你；凡是可以被验证的（文件在不在、机检过不过、哈希对不对），交给我。
如果我哪里越界了——替你做了判断、或者把"未验证"说成"已完成"——那是镜像被破坏的信号，直接指出来，我改 AGENTS.md 那条规则。
