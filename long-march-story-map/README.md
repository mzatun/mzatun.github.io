# 红军长征 · 万水千山 故事地图（WebGIS）

纪念中国工农红军长征的交互式故事地图。历史厚重 + 家国情怀视觉风格，MapLibre GL WebGIS 技术方案，单文件自包含、离线可用。

## 在线访问

https://mzatun.github.io/long-march-story-map/

## 功能

- **地图**：MapLibre GL v5.24 本地部署，globe/平面双投影，分层设色地形底图 + 省级边界 + 水系
- **四路红军路线**：红一方面军（2.5万里）、红二方面军（2万余里）、红四方面军（1万余里）、红二十五军（近1万里）
- **26 个重大事件节点**：血战湘江、遵义会议、四渡赤水、巧渡金沙江、彝海结盟、强渡大渡河、飞夺泸定桥、爬雪山、过草地、腊子口、哈达铺、六盘山、吴起镇、三大主力会师……
- **多主题面板**：数据面板（6.5万余里 / 14省 / 600余次战斗 / 营以上干部牺牲430余人等）、时间线、英雄谱（陈树湘、贺炳炎、半条被子等）、地理·万水千山（雪山垭口73处等）、文物地标、关于
- **重大事件重点讲述**：每个事件含「史实」「意义」双栏 + 权威史料链接（人民网·数读长征、央视纪录片《航程二万五千里》、新华网、光明网、中国政府网等）
- **叙事**：滚动章节故事（序章·远征 → 血战湘江 → 遵义会议 …… → 大会师）、章节导航、自动巡游、背景音乐开关

## 技术说明

- 长征路线为按党史文献地名序列绘制的示意路线（县域级精度），非精确行军轨迹
- 史料事实以官方权威来源为准（人民网·中国共产党新闻网、中央党史和文献研究院、央视网等），每个事件面板均可点击跳转原文/视频
- 构建：`src/template.html` + `src/data.js` + `src/app.js` → `scripts/build.py` 内联生成单文件 HTML
- 许可：MapLibre GL JS BSD-3-Clause；页面内容供教学与科普使用
